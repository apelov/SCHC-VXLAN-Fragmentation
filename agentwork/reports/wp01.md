# WP01 — Reference core: wire codec and CRC-32C

## Changes

- `src/schcvx/crc32c.py`: table-driven CRC-32C (Castagnoli), reflected input/output,
  init/xorout `0xffffffff`. Matches the check value `0xe3069283` for `b"123456789"`.
- `src/schcvx/wire.py`: constants `HEADER_LEN=14`, `RCS_LEN=4`, `UDP_LEN=8`,
  `VXLAN_HDR_LEN=8`, `RULE_ID_0=0`; frozen dataclass `Fragment(rule_id, vni, frame_id,
  index, count, payload, rcs)`; `encode()`/`decode()` implementing the DESIGN.md
  "Prototype wire format" table exactly (RuleID @0, VNI @1-3, Frame ID @4-11, index @12,
  count @13, slice @14.., RCS appended only on the final fragment). `decode()` raises
  `MalformedFragment(reason)` with reasons `"short header"`, `"count < 2"`,
  `"index >= count"`, `"empty slice"`, `"final fragment too short to hold slice plus
  RCS"`.
- `src/schcvx/__init__.py`: re-exports the public symbols.
- `tests/test_crc32c.py`, `tests/test_wire.py`: new test suites (28 tests total).

## Non-obvious choices

- `encode()` validates field ranges (`rule_id`/`index`/`count` fit one byte, `vni` fits
  24 bits, `frame_id` fits 64 bits) and the index/count/payload/rcs consistency rules
  (`count >= 2`, `index < count`, nonempty payload, `rcs` set iff `index == count - 1`)
  with `ValueError`, since these are sender-side programming invariants rather than
  wire-malformation cases — `MalformedFragment` is reserved for `decode()` on untrusted
  input, per the package spec's split between the two.
- For `decode()`, a non-final fragment with zero slice bytes raises `"empty slice"`,
  while a final fragment too short to hold at least one slice byte plus the 4-byte RCS
  raises the more specific `"final fragment too short to hold slice plus RCS"` — the two
  checks don't overlap because the final-fragment branch is evaluated first whenever
  `index == count - 1`.
- `VXLAN_HDR_LEN` is defined here (unused within this module) because the package spec
  lists it as a WP01-owned constant; it is presumably consumed by the sender's MTU-budget
  calculation in a later workpackage.
